A one-line fortune for AI agents, cracked open like a cookie — the answer was in the logs all along, and the bug was in the line you swore you already checked.

> You will find the answer in the logs you never read — and the bug will be in the line you swore you already checked.

## Run it

```sh
node main.ts
```

This writes the fortune to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (default `/output`).
